# Что изменилось — апгрейд портфолио (refreshed edition)

Полный контент и структура сохранены. Менялись только «движок», скорость, адаптивность и визуальные детали.

## 1. Скорость (главный выигрыш)

| Ресурс | Было | Стало |
|---|---|---|
| Постер FoodSource (GIF) | 8.3 МБ | 20 КБ WebP |
| Постер покер-демо (GIF) | 7.5 МБ | 24 КБ WebP |
| BubbleScope: GIF в карточке | 2.2 МБ | MP4 748 КБ + постер 36 КБ |
| foodsource.mp4 | 5.4 МБ | 2.0 МБ (H.264, faststart) |
| poker-chips-cv-demo.mp4 | 4.9 МБ | 3.5 МБ (faststart) |
| flotation-bubble-tracking.mp4 (был MPEG4 @ 26.7 Мбит/с) | 4.8 МБ | 748 КБ |
| ZMetrics-отчёт PDF | 4.8 МБ | 1.1 МБ |
| **Вес репозитория** | **~44 МБ** | **~11 МБ** |

- Шрифты Google Fonts перенесены из блокирующего `@import` в `<head>` с `preconnect` — рендер начинается раньше.
- Видео FoodSource и BubbleScope больше не грузятся при открытии страницы: запуск автоматически при попадании в экран (IntersectionObserver). Экономия ~3 МБ на старте.
- Покер-демо: `preload="none"` — видео качается только по клику на play.
- Всем изображениям добавлены `width/height` (нет скачков-layout, CLS ≈ 0), `loading="lazy"` и `decoding="async"` ниже первого экрана, `fetchpriority="high"` у фото в hero.
- Удалены неиспользуемые GIF (foodsource.gif, poker-chips-cv-demo-compact.gif, flotation-bubble-tracking.gif) — при желании их можно вернуть в репозиторий, ссылки на них из HTML больше не идут.

## 2. Адаптивность

- Добавлены промежуточные брейкпоинты: **1160 / 1024 / 900 / 640 / 440px** (было только 850 и 500).
- Fluid-типографика через `clamp()` — заголовки плавно масштабируются без рывков на планшетах.
- Исправлены наезды элементов в hero-схеме: позиции узлов и подписи пересчитаны, высота эллипса теперь `clamp(340px, 44vw, 560px)` вместо фиксированной.
- Сетка кейсов: 3 → 2 → 1 колонки (в оригинале был резкий прыжок 3 → 1).
- На мобильных кнопки — на всю ширину, карточки без лишней высоты, подпись у эллипса не обрезается.
- `min-height: 100svh` у hero — корректная высота первого экрана на смартфонах (адресная строка браузера больше не «съедает» вёрстку).
- `scroll-margin-top` для всех якорей — заголовки секций больше не прячутся под sticky-шапкой при переходе по меню.

## 3. Визуальный полиш (стиль сохранён, освежён)

- Крупнее типографика: H1 до 104px, H2 до 74px, контакты до 110px; больше воздуха между секциями (`clamp(92px, 10vw, 150px)`).
- Hover-эффекты: карточки приподнимаются с тенью, чип «CV LIVE» вращается, «фотоаппарат» в hero реагирует, кнопки вдавливаются/поднимаются, у ссылок анимированное подчёркивание, стрелки сдвигаются.
- Статистика в hero — с лаймовыми маркерами слева; блок «80%» в карточке LABA.DA теперь стилизован (в оригинале класс `.card-result` был в HTML, но не в CSS).
- Полоски метрики «294mm» анимированно «отращивают» ширину при появлении секции.
- Мобильное меню: плавающая панель со скруглением, анимацией и тенью вместо резкого `display:none/flex`.
- Активный пункт меню подсвечивается при скролле (scroll-spy).
- Шапка получает тень после начала скролла.
- Появление блоков друг за другом (stagger) вместо одновременного.
- `::selection` лаймовый, кастомный скроллбар.

## 4. Доступность и мелочи

- `:focus-visible` — видимая клавиатурная фокусировка на всех интерактивных элементах (цвет адаптируется к тёмным секциям).
- Меню закрывается по `Esc` и клику вне панели, блокирует скролл страницы, возвращает фокус на кнопку.
- `prefers-reduced-motion` полностью уважается (все анимации и автозапуск видео отключаются).
- Print-стили: при печати страницы ничего не «пропадает» из-за анимаций.
- `aria-hidden` на декоративных стрелках, `role="img"` на hero-схеме.
- `defer` у скрипта.

## 6. Код

- CSS переписан с нуля: читаемые секции с комментариями, дизайн-токены в `:root`, убраны дубли правил (в оригинале `.hero` и `.hero-photo` переопределялись в конце файла).
- JS переписан в изолированный IIFE с 5 независимыми модулями-фичами.
- Без сборки и зависимостей — как и раньше: три файла и папка `public/`.

## Как задеплоить

1. Замените содержимое репозитория файлами из архива (или скопируйте поверх, разрешив замену).
2. Закоммитьте и запушьте — GitHub Pages обновится через ~1 минуту.
3. Жёсткое обновление в браузере: Ctrl+Shift+R.
